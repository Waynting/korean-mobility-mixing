腳本 `eda/p56_fig5.py` → `eda/fig/p56_figure5.png` / `.pdf` + `results_p56.json`。
只讀 `results_p39.json` 與 `results_p59.json`（β 讀 `results_p53.json`／`results_p44.json`），
**兩個 Monte Carlo 都不重跑**。數秒。

**一句話結論：圖 5 原本用的是 `p39_recovery.png`，那是診斷圖——150 dpi、標題寫著
「Phase 39 —」、面板標題是階段編號、沒有向量輸出。照那張圖寫圖說，寫出來的會是
**一張不能投稿的圖的說明**，所以它是七張圖裡最後一張沒有圖說的。這一支把它重畫成
投稿版，並且多了一個診斷圖沒有的面板。**

## 1. 為什麼不是「補一個數字清單就好」

原本記的待辦是「`p39_recovery.py` 沒有 `caption_numbers`，補一個再寫圖說」。
補了也不夠：圖說會忠實描述一張標著階段編號、解析度不足、沒有 PDF 的圖。
`p46`／`p47`／`p48`／`p55` 都是「另開一個階段，只讀結果檔、畫投稿版」，這一支照辦。

**回收實驗本身沒有重跑**（要 18 分鐘）。為了畫一張圖去重跑一個 Monte Carlo，
是在「重點正是兩者沒有差別」的地方製造差別的機會。

## 2. 三個面板，中間那個是新的

- **(a) 校準曲面**：dong 層讀回值對合成世界給定的真值，逐 β 一條曲線。這是 `p39`
  第一面板重畫。
- **(b) 反解出來的界對 β**——**診斷圖沒有這一面板**。`p39` 畫的是「5% 分位對 r_true」，
  再讓讀者自己找每條曲線與觀測值的交點。**論文真正宣稱的是那個交點本身**：
  不被拒絕的最大 r_true，作為 β 的函數。直接畫出來，那句話就變成看得見的：
  界隨 β 單調上升（β = 0 的 0.0167 到 β = 0.99 的 0.3205），β 沒釘住之前它什麼都沒說。
  量到的 β 標在圖上（0.9217 首爾臂 到 0.9347 全國臂），在那個位置界仍然低於調查的
  0.2227——**這就是那句話，而且是看得見的而不是斷言的**。實心點代表調查值被排除，
  空心點代表沒有。**β\* = 0.9659 與 β = 0.95 兩條垂直線標在面板上**，理由見第 6 節。
  (a) 面板**只用 `p39` 原本那五條 β**：五條曲線是可讀的上限，而且 `BETA_COLOUR`
  本來就沒有 0.96／0.97／0.98 的顏色；細化網格是為了定位交點，那是 (b) 的工作。
- **(c) 免費的驗證**：`p37` 在真實資料上、不經任何合成世界，量到洞層超額粗化到區層
  還剩多少（27.6%–32.6%，中位 29.8%，202312 那一階 30.1%）。合成的**資料場**讀 32.7%，
  落在帶內；當初信裡提的**原型場**讀 14.9%，差了兩倍多。世界產生器因此被一個
  它從來沒有被擬合到的量檢查過。

## 3. 畫圖前先擋

`p39` 這一邊：`reps` 必須是已發表的 100（不是煙霧測試的值）、rank-1 恆等式 6 項且最差
< 1e-15、曲面對 r_true 單調且隨 β 下降、α = 0 空手臂不是 void、每個 β 的反解單調、
`p39` 存的調查值沒有漂。

`p59` 這一邊（2026-08-27 新增，八條）：`config.reps == 100`、
`A1_surface_bit_exact.max_abs_diff == 0.0`、`A2b_null_arm_bit_exact.max_abs_diff == 0.0`、
`A2_bound_bit_exact.per_beta` 在 0.95 與 0.99 都 `bit_equal`、
`A4_monotonicity.bound_monotone_in_beta`、`A5_inverter_is_p44s.bit_equal`、
`claim.all_below_0p95`，以及**直接比對兩份反解區塊**——
`p59.inversion_refined["0.95"|"0.99"].bound_corrected` 必須等於
`p39.inversion[...]` 的同一個欄位，一位元都不能差。
最後一條是**把兩條網格畫成同一條曲線的執照**，不是裝飾：`p59` 的五片是第二次
Monte Carlo，唯一能和 `p39` 併圖的理由，就是它把 `p39` 自己那兩個 β 原封不動跑回來了。

任何一條不過就在碰到 `plt` 之前停住。**十五個突變全部轉紅**（在記憶體裡改一個鍵、
不動任何結果檔；這邊八條，`p55` 那邊六條 assert 共七個突變，見 phase55 memo 第 7 節）。

## 4. 圖說裡不可以拆開的一句

**界與 β 必須同段出現。** 單獨寫「上界是 0.0167」會被讀成「我們證明真值小於 0.0167」，
而那是 β = 0 那一條——也就是「格子底下什麼都沒有」，正是本文說不成立的假設。
`results_p56.json` 的 `refuses` 欄位把這條規矩寫進檔案裡。

## 7. 為什麼解析式那個數字非記不可

老師建議的寫法是 `r_true ≤ r_obs/(1−β)`。把 β = 0.95 代進去得 **0.3354**，
而調查是 0.2227——**0.3354 > 0.2227，排除不掉**。倉庫實際用的界是反解出來的曲面
（`p39_recovery.py` §39.8），同一個 β 給 **0.18477 < 0.22271，排除得掉**。
**兩者結論相反。** 更難看的是：解析式與調查的交點在 β = 1 − 0.016768/0.222710 =
**0.9247**，落在我們量到的 β 區間（0.9217–0.9347）**裡面**——照解析式寫，
在我們自己量到的 β 上就已經排除不掉了。

所以面板畫的必須是、而且只能是反解曲面。這條規矩寫進了 `results_p56.json` 的
`refuses` 欄位（連同刪掉數格子那一條的理由），而解析值以 note 的形式留著，
是為了讓圖說可以**主動說明我們沒有用它**，而不是讓讀者自己代公式代出相反的結論。

## 8. 面板 (b) 的標題換了

舊標題 `the bound is a bound divided by (1-β)` 講的是界的**形狀**；
新標題 **`the survey is excluded at every β we can measure`** 講的是**單邊的讀法**，
也就是這張圖真正要人看的那句話。它成立的兩個前提都被 gate 擋著：
`A4_monotonicity`（界對 β 單調，所以「β\* 以下全部排除」才是一句話而不是一個猜測）
與 `claim.all_below_0p95`（每一個量到的 β 都在 0.95 以下）。
β\* 本身不進標題，它是 margin，由圖上那條垂直線與引線標籤負責。

## 9. 第三個版式缺陷，這一輪的

β\* 與 0.95 在一條 0→1 的軸上只差 0.016，所以**任何貼在其中一條線上的文字都會壓到另一條**。
第一版把 `β* = 0.966` 沿線豎排，結果卡在 teal 底色帶與 0.95 虛線中間，
第二版改成橫排放進上方留白，又和左上角的圖例撞在一起（圖例那兩行字比看起來長）。
最後的作法是：**標籤放在留白帶靠右（軸比例 0.72, 0.955），用引線指到界與調查線的交點**，
`at β = 0.95 the bound is 0.1848` 則放在中左空白（0.30, 0.62）用引線指到 0.95 那個實心點。
兩條引線一條由上往下、一條由下往上，不相交，也都不穿過曲線。
