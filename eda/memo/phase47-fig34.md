## 3. 改動一：3(b) 背後補上調查自己的虛無（`results_p61.json`）

**為什麼要補。** 舊圖說那句「(b) restates (a) without reference to any null」
既是賣點也是洞：三條頻譜被畫成好像沒有雜訊。p61 把 465 位首爾受訪者的 ego 年齡帶
洗牌 500 次（alter 邊際與每個人的接觸數都保留，死掉的只有配對），量出來的就是
畫在 k = 2 背後的那條帶。

| | σ₂/σ₁ |
|---|---:|
| 觀測（調查，202312，WE，首爾） | **0.6013701617** |
| 置換虛無 中位數 | 0.126622 |
| 置換虛無 p95（宣告在前的逃逸門檻） | 0.158452 |
| 置換虛無 p97.5 | 0.167098 |
| 置換虛無 500 次的**最大值** | 0.211727 |
| 受訪者 bootstrap p2.5 | 0.516123 |
| 受訪者 bootstrap 最小值 | 0.479275 |

觀測超過 500 次的**每一次**（p < 1/500），而且 bootstrap 的下緣（0.516）高於
虛無的上緣（0.167）——**兩個支撐不相交**，主要與次要逃逸準則都過。

順帶一句正是 p32 招牌句的頻譜版重述：被動洞的 0.1237 落在調查自己虛無的
**第 43 百分位**，被動區的 0.0661 在**第 0 百分位**。也就是說，被動矩陣離秩一的
距離，跟把調查的年齡配對整個洗掉之後剩下的距離，是同一個量級。

**畫法上刻意不做的事：不用 KDE violin。** violin 的密度是在線性空間算的，
放到對數軸上會讀成一團對稱的東西，而這正是這條帶必須避免的誤讀。改用**百分位帶**：
p2.5–p97.5 深灰、min–max 淺灰、中位數實線、p95 虛點線（逃逸門檻），
bootstrap 95% CI 是 k = 2 上的一根紅色直條。每一個邊界都是 p61 **報告過**的百分位——
p61 之所以把 500 次抽樣全部存下來，就是為了讓圖畫的是被報告的那個分布，
而不是畫圖時重抽的一個。

視覺上要看到的是：**被動洞的曲線在 k = 2 穿過那條灰帶，調查的三角形高出一個數量級。**

空格診斷也寫進清單：觀測的 15×15 區塊有 **24** 格為零，虛無的中位數是 **8** 格
（p61 宣告過的「虛無帶著同樣的空」那一句其實**沒有成立**，它自己記為 post hoc）。

## 4. 改動二：圖 4 變成「同一個估計量、兩條不同意的軸」（`results_p60.json`）

老師要的是一條 3 箱 assortativity 線，好讓兩個面板量同一個東西。**p60 跑出來，
這個要求背後的假設是反的。**

| | 中位數 | 範圍 |
|---|---:|---:|
| 16 箱 r | 0.019377 | — |
| 3 箱 r（Lim 帶） | 0.082904 | — |
| **3 箱 / 16 箱** | **3.9577** | 3.4705 – 4.7933 |
| 逆著宣告前預測的月份 | **79 / 79** | — |

巢狀階梯（相鄰配對，每一階都是上一階的粗化）16 / 8 / 4 / 2 =
0.019377 / 0.033988 / 0.056344 / 0.086885。**k = 1 是 0/0，不是 0**——把年齡軸壓成
一箱就沒有分割可言，p60 存 `null`，這張圖**不畫**，改用一條灰帶加旋轉註記說明，
結構上對應 (a) 的「unsupported by these data」。

**機制（都在 `results_p60.json` 裡）。** 比值可以拆成兩個都大於 1 的因子：
分子是被吸收進對角的跨組超額（中位數 ×2.2708），分母是邊際集中
（(1−Q₁₆)/(1−Q₃)，中位數 ×1.7100）。而且**在嚴格比例混合下，collapse 之後每一階的
r 都是 0**（max |r| = 4.94e-16），所以升高的不是算子造出來的假象，
而是原本被算成跨組的真實超額被重新標記成組內。

**空間方向相反**：gu/dong 0.4692、city/dong 0.2454。

**為什麼兩條軸不對稱**：空間是**邊際化**（地點被重新配對，年齡分割一動也沒動），
年齡是**重新分割**（分割本身變了，跨箱超額變成箱內超額）。同一個估計量，
兩種完全不同的操作。

### 版面決策，兩個都是刻意的

1. **1×3，不是 2×2。** 2×2 會讓被降級的面板橫跨整個底列，那讀起來是**升級**，
   與本意正好相反。三個並排，降級的那個只是因為要放 16 根有標籤的長條和八個圖例項目，
   才拿到最寬的寬度比（1.0 : 1.0 : 1.3）。
2. **不翻 x 軸讓 (a) 和 (b) 斜率一致。** (a) 往右升、(b) 往右降，
   **這個對立就是結果**。兩邊各加一句註記：「coarsening geography lowers r」／
   「coarsening age raises r」。把軸翻過來讓它們看起來一致，等於把發現刪掉。

## 5. 新增的閘：兩個年齡面板必須是同一組三箱

(c) 的金色橫線來自 `results_p19.json`，(b) 的金色標記來自 `results_p60.json`，
兩者都應該追溯到 `p19_bandwidth.py` 的 `LIM_BANDS`——但**在這一輪之前，
沒有任何一行程式碼 assert 過它們是同一組三箱**。那個字面值一旦搬動，
圖 4 會安安靜靜地退回成「兩個量不同東西的面板」，而這正是這一輪要修的缺陷本身。

作法：腳本裡只留**一份**字面值 `LIM_SPAN = (("0-19", 3), ("20-59", 8), ("60+", 5))`，
(c) 用它擺金線，`gates()` 拿 `p60["anchors"]["A5"]` 的 band map 去對它，
再對 p19 三箱序列的標籤，最後 assert 三箱**按序鋪滿**全部 16 個五歲箱。
另外加上 p60 的 A1／A3／A4 三個 anchor、79/79 的預測失敗、比例混合虛無 max |r| < 1e-12、
與 p37 同一組 79 個月；p61 這邊 assert 58/58 個 anchor 全過，
以及**p61 的虛無是對著 (b) 所畫的那個觀測抽的**（σ₂/σ₁ 與 p32 的頻譜值逐位元相等）。

七個 mutation 測試（拿掉 60+ 的一個箱、讓 0-19 吞掉 20-24、改 p19 的三箱標籤、
換掉 p61 的觀測值、把 79/79 改成 40/79、把比例混合虛無改成 1e-3、把 p61 的 anchor
記成 57/58）**全部照預期變紅**。

## 6. ✅ 圖 4(c) 的端點過濾章（原 4(b)，2026-08-24 結案，內容未動）

**先講清楚它從來不是 8/24 那封信在談的 scope。** 兩者都叫 scope，是兩個問題：

| | 8/24 談的 | 這個面板卡的 |
|---|---|---|
| 問題 | 調查用哪一臂（首爾 465 對全國 1,987） | 移動的**端點過濾**（兩端都在首爾 對 起點在首爾、終點不限） |
| 已回答 | 是（首爾 primary，招牌句降級） | **是，2026-08-24** |

結案依據不是挑一個數字，是 `phase1c-scope.md` §3 那條**由估計對象決定**的規則：

| 估計對象 | 正確的端點過濾 |
|---|---|
| 首爾內部的**共現**（混合矩陣本身） | 兩端都在首爾 |
| 居民的**行為**（目的組成、出發率、ρ̂） | 起點首爾、終點不限 |

面板講的是**聚合把年齡結構吃掉**，而那個結論**在兩個過濾下都成立**：

| | 兩端首爾 | 起點首爾 |
|---|---:|---:|
| 三箱保留的跨度 | 47.6% | 45.9% |
| 三箱 60+ | +0.075 pp | **−0.157 pp** |
| 箱內 80+ | +0.844 pp | **+0.554 pp** |
| 換號位置 | 65-69/70-74 | 70-74/75-79 |

⚠️ **兩個標記都取自 `p18b`，沒有一個取自 `p19`，這是刻意的。** `p18b` 是**補值之前**量的，
所以它的兩端序列只在 20-44 以外等於長條——而 20-44 正是唯一有遮蔽的地方。
拿 `p18b` 的起點首爾值去配 `p19` 的長條，會把補值當成 scope 的效果賣掉：
那個落差最大 **0.4757 pp**（20-24），比 80+ 的整個 scope 位移還大。
`gates()` 把「20-44 以外兩者相差 ≤ 0.005 pp」asserted 起來，而不是假設它。
**金對藍實線讀補值，藍實線對藍虛線讀 scope。**
