# 2020 對 2026 —— 誰回來了，扣掉覆蓋率之後

*2026-08-18。腳本 `eda/p23_baseline.py`。產出 `eda/results_p23.json`、`fig/p23_baseline.png`、
`derived/rho_2026_numerator.parquet`。用的是 Phase 2a 拉進來的 2026-06／2026-07。*

老師對擴充時窗的提問是分配性的：**疫情之後年齡別混合回到基線了嗎，誰沒有回來。**
兩個 2026 月份已經在磁碟上，所以不必等 78 個月全量攝入就能給第一個答案。

比較的是 **2020-06 對 2026-06、2020-07 對 2026-07**——同一個日曆月，
所以季節性是**依建構**固定住的，不是被模型控制掉的；而兩個月份互為**獨立複本**。

---

## 1. 為什麼這個比較識別得出來，以及在哪裡識別不出來

$\hat\rho=\kappa\lambda$，所以六年的 $\hat\rho$ 變化要先把覆蓋率變化定界才是行為宣稱。
兩個事實讓大部分齡段的界很緊：

- **20–59 在 2020 年就已經飽和**（兩份調查都是 98.7–99.9%），所以 $\kappa$ 動不了超過一個百分點；
- **持有率不可能超過 100%**，所以未發布的 2026 波次被夾在「2025 觀測值」與 100 之間。
  60대 在 2025 是 99.8%（NIA）／98.2%（방송매체），夾出來的漂移帶只有**兩個百分點寬**。

| 調查齡組 | κ 漂移 2020→2026 | 帶寬 |
|---|---|---|
| 20s／30s／40s | +0.3…+0.6% | **0.2–0.3 pp** |
| 50s | +0.1…+1.3% | 1.2 pp |
| **60s** | **+7.1…+9.1%** | **2.0 pp** |
| **70+** | **+50.2…+96.9%** | **46.7 pp** |

**70+ 的界寬是結果不是缺陷**——它精確地說出這份資料對哪些齡組講得出話。
兩份調查都用，取**聯集**，所以答案永遠不比較悲觀的那一份好。

## 2. 結果：每一組都回來了，而且回來的幅度隨年齡遞增

只有**兩個日曆月複本都同號**才算數（見 §3）。12/16 組通過：

| 齡組 | 反解 λ 變化 | | 齡組 | 反解 λ 變化 |
|---|---|---|---|---|
| 10–14 | **+111.6…+125.3%** | | 45–49 | +20.1…+20.4% |
| 15–19 | +22.6…+30.5% | | 50–54 | +15.7…+17.1% |
| 25–29 | **+7.0…+7.1%**（最小） | | 55–59 | +19.6…+21.1% |
| 30–34 | +17.0…+17.2% | | **60–64** | +28.1…+30.4% |
| 35–39 | +25.5…+25.7% | | **65–69** | **+41.9…+44.5%**（最大） |
| 40–44 | +28.6…+28.8% | | 80+ | +21.6…+59.4% |

**壯年組的界窄到 ±0.3 pp**——因為 2020 年他們的持有率就已經到頂，κ 幾乎沒有空間動。
這是本專案第一次拿到**接近點識別**的跨年行為變化。

**梯度是單調上升的：25–29 的 +7% 到 65–69 的 +42–45%。**
10–14 的 +112–125% 是另一回事——2020 年 6/7 月韓國中小學仍在分階段／遠距，
那一格量到的主要是**停課政策的解除**，不是混合行為的恢復，要分開講。

⚠️ **框架上的保留，不可以掉：2020-06／07 本身就是疫情月份，不是疫前基線**——本專案沒有 2019。
所以正的 λ 是「相對疫情年的恢復」，**不是「回到 2019 的水準」**。
而且高齡在 2020 年掉得更深（Phase 1c 量到 70–74 在 2020 年內的 λ 是**下降**的），
所以他們較大的恢復幅度有一部分只是**起點的洞更深**。這兩件事要一起寫。

## 3. 複本紀律：兩組被降級

用兩個日曆月當獨立複本，並**要求兩者各自同號**才算數。這不是形式主義：

| 齡組 | 六月 λ | 七月 λ | 判定 |
|---|---|---|---|
| **20–24** | **+20.4…+20.5%** | **−2.3…−2.2%** | ⛔ 複本互相矛盾 |
| **75–79** | +7.5…+40.9% | −0.1…+30.9% | ⛔ 複本互相矛盾 |

**兩者的平均會看起來像一個乾淨的正結果**（20–24 平均 +9.0…+9.1%），
而事實是七月的複本說它是負的。**只有一個月份的證據不足以支撐這種宣稱。**

## 4. 一個差點通過的算術錯誤，以及裝上的閘門

第一版的去重 CTE 把 `arr_hour`、`d_dong`、`mtype` 從鍵裡漏掉了，
於是 `min(pop)` 不是在去重、而是在**跨小時與跨目的地取最小值**——
分子被安靜地除以約 30 倍。

**危險的地方在於比值仍然看起來合理**：跨齡組的形狀、跨月的變化率都還是「像那麼回事」，
只有**水準**是錯的（$\hat\rho$ 掉到 0.001–0.009，而正確範圍是 0.24–0.71）。
第一版跑出來的結論甚至是**符號相反的**（高齡「下降 31%」）。

已加上閘門：`p23_baseline.py` 現在會檢查 $\hat\rho$ 落在 0.05–3.0，
否則**直接中止**而不是把結果印出來。理由寫在程式碼裡：
**在這個管線裡，錯誤的水準配上合理的比值，是最容易被當成發現的失敗模式。**

## 對計畫的淨影響

**這是 Phase 6（把時窗擴充變成研究問題）的第一個實質結果**，而且它只用了兩個月份。

**新增的具名待辦：**
1. **拉 2025-03 與 2025-12。** 它們同時解開 R2（飽和期的 3→12 月對比）與 R3（正常學年）。
   `dl_mobility.py --list` 目前被伺服器斷線（`RemoteDisconnected`），
   推測是 Agent C 連拉兩個月之後的速率限制，晚點重試。
2. 10–14／15–19 的變化要跟**學校政策**分開敘事，不能混進「混合恢復」。
3. 70–74 仍然跨零，75–79 複本矛盾——**高齡那一段要靠更多月份，不是更好的方法**。
