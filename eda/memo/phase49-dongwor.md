# Phase 49 — 洞級換成取後不放回，讀數掉 4.29%，而兩個人都低估了它

腳本 `eda/p49_dongwor.py` → `results_p49.json`。直接 `import p44_beta.collapse`，
不重寫運算子；`results_p26.json` 一個位元都不動。

**一句話結論：老師 8/24 信裡「533 應該可忽略」不成立。同一個估計量在已發表的
primary 格上，取後放回讀 0.02115386、取後不放回讀 0.02024732，差 −4.29%。
結論不動（差距是 10 倍不是 1.04 倍），但這個數字必須寫出來，不能讓讀者自己推。**

---

## 1. 為什麼要做

`p44` 在**場館**尺度上發現配對慣例會動：一個場館平均 4.22 人，取後放回把六分之一的
質量丟到對角線上，讀數 0.43615 對 0.24872，差 43%。那件事決定了調查臂報哪個數。

被動側（`p26_matrix.py:141`）從頭到尾用取後放回，沒有跑過另一種。理由一直是尺寸論證
——格子裡是好幾百人不是四個人——但「可忽略」始終是一個論證而不是一個數字。老師的信
把它當定論用（「洞級中位 533 人應該可忽略」），所以它得變成量出來的東西。

## 2. 宣告了什麼，以及為什麼每一項都事前固定

1. **格**：202312 | WE | 洞 | holiday-free，因為那正是 `p32`/`p33`/`p44` 引用的
   0.02115385938228908。換一格就是回答論文沒有報的數字。
2. **配對尺度**，這是這裡唯一真正的陷阱。`p26_matrix.py:129` 在配對**之前**先把
   每格人數除以該曜日在當月出現的次數，所以 X 是「平均一天」的到達數、是浮點期望值
   不是整數人頭。這件事有後果，因為兩種慣例不是同一類函數：

   ```
   取後放回     sum_g w_g n_a n_a' / n_.              對 n 是一次齊次
   取後不放回   sum_g w_g (n_a n_a' − δ n_a)/(n_.−1)   不是
   ```

   `p44_beta.py:113-115` 用「運算子對 n 是一次齊次」來正當化重新縮放群組。那句話
   **只對取後放回那一支成立**。所以尺度要選、要辯護，不能繼承。

   **宣告主值：平均日尺度。** 估計量整個構造都在說共現的單位是「一天、一格」——
   `pop_day` 就是為此存在，`common.py` 記著 `이동인구(합)` 是月內加總、不先除掉出現
   次數就不能比。同一格但不同天的兩個人沒有見面。
   **宣告界：月加總尺度**，n 大四到五倍、修正相應變小。報出來讓讀者看見答案不是
   尺度選擇的產物：主值是保守的那一端（−4.29% vs −0.96%）。
   **沒做：把 X 取整。** 取整會動到取後放回的值，打斷 49.0a 這個唯一把本階段綁回
   `p26` 的錨。
3. **主導的規模統計量**：事前宣告用到達加權平均 4,052。**這一項事後證明是錯的**，
   見第 5 節。宣告照原樣留著。
4. **階梯而不是單一數字**：洞／區／市。修正如何隨群組大小衰減**就是**機制那句話。
5. **停損**：取後放回的重建若不能逐位重現 `p26` 已發表的矩陣，直接中止。

## 3. 三個錨（49.0）

- **49.0a｜X 就是 p26 的 X，逐位。** 用 `p26_matrix.py:141` 自己那一行算式重建，
  `max abs diff 0.00e+00`。這一條必須逐位，因為只要有差，就代表 `wide_counts`
  沒有重現 p26 的格表，底下整個階段講的是另一個估計量。
- **49.0a2｜collapse 是同一個運算子，到機器精度。** `1.10e-14`。`collapse` 先縮放
  列再收縮一次，`p26` 先除再收縮，**求和順序不同而浮點加法不可結合**。這與 `p36`
  釘 `threads=1` 是同一個效應。照實報：逐位與否是關於運算順序的宣稱，這一對沒有
  相同的順序；重要的是運算子是 `p44` 的，所以場館尺度與格尺度是同一個估計量在兩個
  群組大小上，不是兩份剛好吻合的實作。
- **49.0b｜單群組閉式。** 一個群組內取後放回必然 r = 0，取後不放回恰好是 −1/(n−1)。
  在 n = 533 / 1,080 / 4,052 / 17,856 四個格尺度上都對到 1e-12 以內。
  ⚠️ 這一條第一版寫錯：把全部質量放在單一年齡帶，而那時 Newman 的分母 1 − Σa² 等於
  0，回傳 nan。閉式對**任何**跨兩帶以上的組成都成立，改用資料自己的年齡邊際之後就過。
- **49.0c｜對照逐對列舉。** 一支刻意笨拙的 O(帶²) 迴圈，一行都不與 `collapse` 共用，
  WR 2.12e-16、WOR 2.18e-16。

## 4. 結果

| 尺度 | n 中位 | n 到達加權 | 取後放回 | 取後不放回 | 相對差 |
|---|---:|---:|---:|---:|---:|
| 洞（424） | 533 | 4,052 | 0.021154 | 0.020247 | **−4.2854%** |
| 區（25） | 13,972 | 37,401 | 0.009854 | 0.009800 | −0.5461% |
| 市（1） | 462,360 | 732,514 | 0.004922 | 0.004920 | −0.0439% |
| 場館 | 4.22 | — | 0.436147 | 0.248718 | −42.97% |

場館比洞大 **10.0 倍**。**修正大的地方正是群組小的地方，而場館小於任何行政單位**
——這一句把機制講完了，而且它不需要「格子裡有幾個人」這個中間變數。202402 同向
（洞 −4.63%）。

尺度檢查：平均日 −4.29% 對月加總 −0.96%，比值 0.224，而 n 的比值約 4.3，
與 1/n 一致；取後放回那一支在重新縮放下**完全沒動**（0.0e+00），正如一次齊次所要求。

## 5. 事前宣告的預測失準，這才是本階段的發現（49.4）

宣告預測 0.025%、並寫下「超過 1% 就代表尺度慣例用錯了」。實測 −4.29%。慣例沒錯
（49.2 顯示答案照 1/n 走，49.0 全過），錯的是預測，而且錯了兩層：

1. **漏掉 1/r 放大。** 修正相對於矩陣**總質量**是 1/n 量級沒錯，但 r 是一個只有
   0.0212 的對角**超額**。相對於總質量的擾動，相對於超額就是 47 倍大。這個專案裡
   每一句「格子很大所以不可能有影響」，比較的都是錯的基準。
2. **主導統計量選錯。** 被移除的對角線總和是 Σ_g w_g n_g/(n_g−1)，而 n_g/(n_g−1) → 1，
   所以修正量 ≈ 群組數 × w，除以總質量就是 **1/算術平均**。每個群組每個人丟掉一個
   自我配對，所以每個群組等權，與它多大無關。從實測反推的有效 n 是 **1,104**，
   對上算術平均 1,080（比值 1.02）；中位 533 給 −8.89%（老師用的，偏強 2.07 倍），
   到達加權 4,052 給 −1.17%（本檔宣告的，偏弱 0.27 倍）。

**宣告區塊沒有事後修改。** 看到答案再挑統計量，正是宣告區塊存在的目的所要防的事。

## 6. 一件沒人問的附帶結果（49.5）

已發表的比較目前**混用兩種慣例**：被動側取後放回（`p26`）、調查側取後不放回（`p44`）。
`p44` 換了調查側的慣例、沒換被動側，因為當時假設被動側不受影響。它受影響 4.29%。

```
照現況     調查 WOR 0.24872 / 被動 WR  0.021154 = 11.758x
統一慣例   調查 WOR 0.24872 / 被動 WOR 0.020247 = 12.284x
```

差距移動 +4.48%，而且是**變大**的方向。這不推翻任何東西（10 倍不是 1.04 倍），
但要引用的那個比值應該用同一種慣例算出來。這件事往下傳到 β，見 `phase53-natbeta.md`
第 3 節。
