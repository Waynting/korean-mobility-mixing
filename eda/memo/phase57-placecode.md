# Phase 57 — Q5 那個沒清掉的 etc 旗標，以及它對 `p27` 多地點率的影響

*2026-08-24。腳本 `eda/p57_placecode.py`。產出 `eda/results_p57.json`。
起因不是一次分析，是為了寫 `Email_Discussion/nims_enquiry_20260824.md` 而把 `[CHAE]`
的五個釋出檔逐欄讀過一次。*

**一句話結論：`p27` 的「10.5% 的接觸有多個地點」把研究者改編碼留下的殘留旗標算成了
第二個地點；不算它是 4.48%。哪一個對是詢問信的第 1 題，所以兩個都報、都不採用。**

---

## 1. 事實

`results_main_survey.csv` 的 `Q5_1..Q5_8` 是「選了就填碼、沒選就空白」。逐列數：

| code | 該碼列數 | 同時設了 `Q5_8` | 佔比 | 其中沒有第三個碼 |
|---|---:|---:|---:|---:|
| 1 家戶 | 63,603 | 1,309 | 2.06% | 790 |
| 2 職場 | 26,142 | 145 | 0.55% | 114 |
| 3 教育設施 | 17,519 | 2,205 | 12.59% | 2,000 |
| 4 宗教設施 | 2,216 | 27 | 1.22% | 13 |
| 5 餐飲 | 16,579 | 1,030 | 6.21% | 458 |
| **6 醫院** | **2,016** | **2,016** | **100.00%** | 1,912 |
| **7 戶外** | **3,210** | **3,210** | **100.00%** | 2,814 |

帶 code 8 又剛好只有一個其他碼的列共 **8,101**。

醫院與戶外**一列不差**全部帶著 `Q5_8` 與一段韓文自由文字——這是改編碼把原本的
「其他」留在原地沒清掉，不是受訪者真的同時在兩個地點。

## 2. 兩個慣例

| | 多地點率 | 家戶＋其他 |
|---|---:|---:|
| 逐字（`p27` 已發表） | **10.5325%** | 3.3773% |
| 不算殘留旗標（primary） | **4.4769%** | 2.7867% |

旗標單獨解釋掉 **6.0556%** 的接觸。

## 3. 錨

逐字慣例必須逐位重現 `results_p27.json` 的 `multi_place_share`
（`0.10532531993780649`）與 `household_plus_other_share`，重現不了就 `assert` 中止。
錨值是**從 `results_p27.json` 讀進來**的，不是打在腳本裡的，所以兩邊不可能各自漂走。
133,776 列的列數也對。

**這個錨不是套套邏輯**：它證明本檔與 `p27` 讀的是同一批列、同一條規則，
於是下面那個差異只能來自慣例，不能來自重寫。

## 4. 為什麼不改 `p27`

`results_p27.json` 這一輪是唯讀的（CLAUDE.md、`eda/archive/README.md`），
而且 p27 的矩陣被 `p32`／`p44`／`p53` 錨著。本階段 `touches_nothing` 宣告了
`results_p26/p27/p44`，只重讀 CSV、只寫自己的檔。

## 5. 還沒定的

**哪一個慣例才對，是 2026-08-24 寄給 NIMS 那封信的第 1 題**，還沒回。
描述子把 Q5 寫成單選、Technical Validation 也描述了這個改編碼，所以 primary 標成
「不算殘留旗標」——**但那是一個讀法，宣告區塊裡標明了是讀法**。

回覆到了之後：若確認是改編碼，`phase7-survey.md` §0 那句改成 4.48%，並在正文引用時
指向本檔；若不是，逐字慣例就是對的，本檔仍然有用，因為它把那 6.06% 是什麼講清楚了。

**目前沒有任何下游消費這個檔案。** 它存在是為了「回覆到之前就把數量量出來」，
而不是回覆到之後才開始量。
