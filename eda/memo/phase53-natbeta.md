# Phase 53 — β 的全國臂，改用全國人口加權

腳本 `eda/p53_natbeta.py` → `results_p53.json`。`p44_beta` 原封不動 import，
`POP` 從外面設；`results_p26.json` 與 `results_p44.json` 都不動。

**一句話結論：老師 8/24 信裡「β 對 scope 不敏感（0.922 對 0.933）、招牌句敏感」
這個不對稱**成立**，而且修正之後更清楚——但 0.933 這個數字在修正前不是全國數字。
修正後全國臂是 0.9347，首爾臂 0.9217 不動，跨 scope 差 0.0130。**

---

## 1. 這是與 p50/p51 不同的第二個病灶

`p44_beta.py:168-172` 把 venue 表事後分層到 `POP`，而 `p44_beta.py:206-211` 把 `POP`
設成 `results_p26.json["population"]["202312"]`——首爾的。**兩個 scope 都是。**
所以 0.9326 不是一份全國讀數，是全國受訪者被重新加權到首爾年齡結構上的結果。
目前的 scope 比較變動了「誰回答」，卻沒有變動「加權到哪個人口」，只做了一半。

`symmetrise(C, pop)` 是互反性修正，這一個是 p27 的事後分層慣例。兩者共用一個成因
（一支首爾向量被到處使用），此外毫無關係，修法也不一樣。

## 2. 為什麼是新階段

`p44_beta.py:241-244` assert 首爾加權的調查矩陣重現 `p32` 已發表的 0.22270993，
容差 1e-12。那個錨之所以是**恆等式**，正是因為加權是 `pop_a ×（該帶每位受訪者的
接觸數）`、用的是 p27 的 pop。就地改 `POP` 等於為了做出一個新數字而打斷一個已發表的
錨——完全反了。所以 p44 原樣 import，`POP` 從外面設，與 `p40` 已經在用的
`import p32_pmix as P32` 是同一個模式。

## 3. 結果

錨（53.0）：兩個已發表的 venue 讀數都逐位重現，
`0.24871774193970334` 與 `0.21407074732086337`，|diff| 都是 0.0e+00。

| 臂 | r_true | β |
|---|---:|---:|
| 全國 pooled，全國加權（**修正後、報這個**） | 0.25665 | **0.9347** |
| 全國 pooled，首爾加權（已發表） | 0.24872 | 0.9326 |
| 首爾 202312，首爾加權（不動） | 0.21407 | 0.9217 |

全國臂的 r_true 往上移 +3.19%。

**老師要的不對稱，量出來是：**

```
β    跨 scope ： 0.9217（首爾）對 0.9347（全國）    差 0.0130
招牌 跨 scope ： 3.69（首爾）對 1.17（全國）        差 3.2 倍
```

所以那個論證站得住，而且比原本更清楚（已發表的差是 0.0109，修正後 0.0130——
仍然是小的）。β 是調查內部的場館分解，招牌句是跨人口的整張矩陣比較，
所以 β 能承重、招牌句不能。這一段可以照原意寫進正文，只要換上 0.9347。

## 4. 一個往下傳的東西：混用慣例（53.2）

`p49` 發現這個比較的兩側用不同的配對慣例：r_true 是取後不放回（p44），
而被動讀數 `R_OBS_CORRECTED = 0.01676780` 承自 p26 的取後放回矩陣。
β 是兩者的比值，所以這個不一致直接落在它身上。

```
被動讀數 0.016768 → 0.016049（套 p49 的 −4.2854%）
全國（全國加權） β 0.9347 → 0.9375
首爾            β 0.9217 → 0.9250
```

β 上升，因為被動讀數變小就代表被回收到的真相更少。

**這是敏感度，不是主值。** β 的定義是 p44 的，本階段不重新定義它。
但如果正文要把 β 當成一個量出來的量來報，這兩個數字應該一起出現。
