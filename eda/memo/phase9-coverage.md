# Phase 9 — KT 的年齡別覆蓋率剖面(從遮蔽門檻反推)

*狀態:完成 · 對應決策:A1 的實證邊界 · 產出:一個原始資料沒有記載的覆蓋率剖面*

八個月的面板讓一件本來做不到的事變得可行:**把 KT 觀測到多少人這件事,從遮蔽門檻反推出來。** 這是一個資料本身沒有揭露、也沒有任何文件記載的量,而它正是識別假設 A1 的核心。

## 9.1 一個被否決的假設:發布值不是權重的整數倍

如果發布值 = 擴大權重 × 整數裝置日數,那麼除以權重就能還原原始樣本數,而遮蔽格也會從「落在 [0,3) 某處」變成「恰好是 1 或 2 台裝置」。這會大幅收緊審查界並給出抽樣變異。

**檢定:找出能整除某分層內幾乎所有發布值的最大公因數。結果是找不到。**

| 候選除數(0–9 歲 F,一月,1495 個相異值) | 解釋率 |
|---|---|
| 6.050(= 最小值) | 4.0% |
| 3.025 | 4.5% |
| 2.017 | 5.7% |
| 1.210 | 4.9% |

32 個分層**全部**失敗(門檻 98%)。降到單一洞的層級也一樣(解釋率 2–6%)。

**但降到單一 OD 格子的層級,量化結構就出現了。** 例如 `1124080 → 1124077, 19 時, EE, 0–9 歲 F` 的七個星期別值:

```
56.02  28.31  34.30  28.06  140.73  56.32  27.78
```

27.78 / 28.06 / 28.31 ≈ 28;56.02 / 56.32 ≈ 2×28;140.73 ≈ 5×28。

> **結論:擴大權重是「格子 × 日」層級的,不是分層層級的常數,而且帶 ±1–2% 的抖動。** 月內加總混合了權重略異的日子,所以沒有全域公因數。
>
> **後果:原始裝置數無法還原,[0,3) 的區間審查維持不變(決策 D4 不變)。**

### 讀法(注意兩個偏誤方向)

1. **這些是權重的上界。** 熱門格子裡沒有任何一天只有一台裝置,最小值就是好幾台的和。p10 比中位更接近真值。
2. **20–44 歲的數字被審查扭曲**(表中只用未遮蔽值,而未遮蔽值不可能低於 3),所以那幾層的真實權重比表上低。
3. **0–19 與 45+ 的數字沒有這個問題**(遮蔽率 ≈ 0),可以直接讀。

### 覆蓋率剖面

把權重讀成「KT 觀測到的比例的倒數」:

| 族群 | 每 N 人觀測到 1 人 |
|---|---|
| 0–9 歲兒童 | 約 28 |
| 10–14 歲 | 約 6 |
| 15–19 歲 | 約 4 |
| **45–59 歲(覆蓋最好)** | **約 3.2** |
| 65–69 歲 | 約 4.1 |
| 70–74 歲 | 約 4.6 |
| 75–79 歲 | 約 5.9 |
| **80+ 歲** | **約 9.4** |

**覆蓋率在年齡上是一個清楚的 U 型:兒童最差(28×)、壯年最好(3.2×)、最高齡再度變差(9.4×)。**

### 這直接回答了 ../../reference/EDA.md Phase 3 的一個問題

> 特別看高齡:長輩機/非智慧機在 KT 網內是否被捕捉,決定 65+ 分層響應可不可信。

**答案:有被捕捉,但捕捉率只有壯年的三分之一(80+ 是 9.4× vs 45–59 的 3.2×)。**

所以 65+ 的分層響應**不是「沒有訊號」,而是「訊號被放大三倍」** —— 這意味著:

- 點估計仍然可用(遮蔽率為 0,沒有選擇偏誤);
- 但抽樣噪音比壯年大約 √3 ≈ 1.7 倍;
- 而且 A1 在這一端最脆弱:如果疫情期間長輩的手機攜帶行為變了,9.4 倍的放大會把小小的行為改變放成大偏誤。

**這正是 [Phase 10](phase10-response.md) 裡 80+ 的高劑量敏感度必須外部校準才能主張的原因。**

原文只把第一個寫死,另外兩個是從上表的數字反推出來的:

1. **格子 = `(o_dong, d_dong, arr_hour, mtype, age, sex)`,最小值取在 `dow_n` 上;

2. **只收「七個星期別裡至少出現 4 個」的格子。** 這一步原文沒寫,但它就是上表 `格子數`
   那一欄的出處:16 個齡組的格子數在 `n_dow ≥ 4` 下**逐格完全相同**(12,898 / 80,681 /
